# MT-Opening: Interactive Game Launcher Anak TK 🎒✨

Game launcher interaktif berbasis web untuk pembuka aktivitas belajar anak TK / PAUD.

## 🌟 Fitur Utama
- **Video Looping Layar Tunggu (`Loop.mp4`)**: Animasi pemandangan sekolah ceria yang berputar halus terus-menerus.
- **Papan Judul Kartun**: Papan gantung kartun yang bergoyang santai (*gentle sway*) dengan hiasan balon & bintang ramah anak.
- **BGM Ceria Otomatis (Web Audio API)**: Musik ceria synthesizer anak-anak bergaya xylophone/marimba tanpa perlu unduh audio tambahan.
- **Tombol Mulai Bouncy 3D**: Tombol besar hijau mencolok yang mudah ditekan anak kecil.
- **Transisi Zoom In (`Zoom.mp4`)**: Ketika tombol Mulai dipencet, langsung memutar video zoom masuk ke sekolah dan **otomatis freeze / berhenti di frame terakhir**.
- **Layar Sambutan Ramah Anak**: Efek kembang api/konfeti dan kartu selamat datang ceria.

## 🚀 Cara Menjalankan
Cukup buka file `index.html` langsung di browser Anda (Google Chrome / Microsoft Edge).
